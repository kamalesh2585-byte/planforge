### Common Issues

**Port already in use?**
```bash
# Find and kill process on port 5173
netstat -ano | findstr :5173
taskkill /PID <PID> /F
```

**Dependencies won't install?**
```bash
rm -rf node_modules package-lock.json
npm install
```

**Hot reload not working?**
```bash
npm run dev
```
